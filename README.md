# coffee-sales-sql-eda
Repositori ini berisi proyek Exploratory Data Analysis (EDA) untuk dataset penjualan coffee shop menggunakan SQL (PostgreSQL). Analisis dilakukan untuk memahami performa penjualan melalui agregasi transaksi, kuantitas, dan revenue; mengidentifikasi kategori serta produk dengan kontribusi revenue terbesar; serta mengevaluasi pola penjualan berdasarkan waktu (jam dan hari) dan tren pendapatan harian. Output utama proyek mencakup kumpulan query SQL yang terdokumentasi, hasil ringkasan temuan, dan insight bisnis yang dapat ditindaklanjuti. Rekomendasi diberikan secara sederhana untuk membantu pengambilan keputusan operasional (misalnya optimasi jam ramai, pengelolaan stok produk populer, dan strategi bundling). Proyek ini dibuat sebagai portofolio analitik berbasis SQL dan dapat dijalankan ulang pada database lokal untuk mereproduksi hasil.
